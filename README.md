# 🤖 基于 STM32F4 与步进电机的自平衡小车 (Stepper Motor Balancing Robot)



本项目是一个高性能的两轮自平衡机器人，区别于传统的直流电机方案，本设计采用**开环步进电机**作为驱动核心。通过改进的串级 PID 算法和独特的转向平滑策略，成功解决了步进电机在低速大扭矩工况下的**原地转弯抖动**难题。

## ✨ 核心亮点

- **🚀 步进电机驱动**: 使用 STM32 定时器产生精确脉冲，控制 42 步进电机，实现高扭矩、低转速的精准控制。
- **🧠 智能防抖转向**: 
  - 独创“比例型 + 一阶滤波”转向算法，彻底消除传统积分型转向带来的启动滞后和松手冲击。
  - 转弯时动态切断速度环，避免积分累积导致的震荡。
  - 直立环动态参数调整（Kd=0, 目标倾角补偿），顺应物理离心力。
- **🎮 ELRS 遥控支持**: 集成 ExpressLRS (CRSF 协议) 接收机，低延迟、高可靠性遥控体验。
- **🛡️ 多重安全保护**: 倾角超限自动停机、遥控器信号丢失保护、上电软启动。
- **⚙️ 自动校准**: 开机自动寻找机械零位 (`Zhongzhi`)，适应不同装配误差。

## 📋 硬件清单

| 部件 | 型号/规格 | 备注 |
| :--- | :--- | :--- |
| **主控板** | STM32F411RE (Nucleo-64) | 主频 100MHz，浮点运算单元 |
| **姿态传感器** | MPU6050 | 使用 DMP 库解算姿态，降低 CPU 负载 |
| **电机** | 42 步进电机 (1.8°) | 1.7A, 保持扭矩 > 0.4Nm |
| **电机驱动** | TB6600 / DM542 | 细分设置为 8~16 细分 (推荐) |
| **遥控系统** | ELRS 发射机 + 接收机 | 使用 CRSF 协议 |
| **电源** | 3S LiPo 电池 | 11.1V, 2200mAh 以上 |
| **结构件** | 亚克力/铝合金支架 | 双层结构，重心适中 |

## 🏗️ 软件架构

本项目采用模块化设计，核心控制频率为 **200Hz (5ms)**。

```text
ControlLoop (5ms)
├── 数据读取 (MPU6050 + ELRS)
├── 直立环 (Balance PD)
│   └── [转弯模式]: Kd=0, Kp↓, 目标角度偏移
│   └── [直行模式]: 标准 PID
├── 速度环 (Velocity PI)
│   └── [转弯模式]: 输出强制归零 (防抖动核心)
│   └── [直行模式]: 维持车速稳定
├── 转向环 (Turn Filter)
│   └── 比例目标 + 低通滤波 (无积分累加)
├── 指令合成 (Moto = Balance + Velocity ± Turn)
├── 加速度限制 (S 型曲线限幅)
└── PWM 输出 (Timer Toggle Mode)
